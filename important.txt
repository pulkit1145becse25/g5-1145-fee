JAVASCRIPT
javaScript is a programming language used to make web pages interactive and dynamic. It allows developers to perform calculations, handle user actions, validate forms, and update webpage content without reloading. JavaScript works with HTML and CSS to create attractive and functional websites. It is also widely used with React.

summary
 javaScript:Programming language used to make websites interactive and dynamic.

 Functions
A function is a block of reusable code that performs a specific task. Functions help reduce code repetition and make programs easier to understand. In JavaScript, functions can accept parameters and return values. They can be called whenever required in a program.

summary
Reusable blocks of code that perform specific tasks efficiently.

USE STATE()
State is an important concept in React used to store and manage changing data inside a component. When state changes, React automatically updates the user interface. The useState() hook is commonly used to create state variables and update their values.

summary
State: Stores changing data and automatically updates React user interfaces.

Forms
Forms are used to collect information from users, such as name, email, password, and phone number. HTML provides elements like input, textarea, and select. In React, forms are managed using state and event handlers. Forms are commonly used for login, registration, and feedback pages.

summary
 Collect user information through input fields and other elements.

onSubmit
onSubmit is an event handler used in React forms. It executes a function when a user submits a form. It is commonly used to collect user information, validate input, and process form data. Example: <form onSubmit={handleSubmit}>. It helps manage form submission without unnecessary page reloads.

summary
 Event handler that executes when users submit forms.

Validation
Validation is the process of checking whether user-entered information is correct and complete. It helps prevent incorrect data from being submitted. For example, email validation checks email format, while password validation checks password requirements. Validation improves application security, accuracy, and user experience.

summary
 Checks user input for correctness, completeness, and required formats.
